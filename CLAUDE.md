# Development Rules

1. Make only explicitly requested changes.
2. Read only files relevant to the current task.
3. Never scan the entire repository unnecessarily.
4. Exclude `.venv`, caches, generated files and large datasets from routine exploration.
5. Preserve existing code, functionality and layout.
6. Never refactor unrelated code.
7. For minor UI changes, run targeted checks only.
8. No full test suites or browser automation unless requested.
9. Avoid unnecessary tool calls and repeated attempts.
10. If a simple task becomes complex, stop and explain.
11. Keep responses concise.
12. Never overwrite unrelated changes.
